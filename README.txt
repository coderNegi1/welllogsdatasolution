# WellLogs Data Solution — multipage HTML template

## Pages
- `index.html` — Home
- `products.html` — Services
- `solutions.html` — Solutions
- `custom-design.html` — Custom project support
- `about.html` — About Us
- `contact.html` — Contact / enquiry form

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before publishing
1. Replace `info@welllogsdatasolution.com` with your official email.
2. Connect the contact form to a real email service or backend. It is demo-only.
3. Replace sample stock photos and text with your real services, projects, and company details.
4. Add your real phone, address, legal pages, and social links if needed.
5. The website uses Google Fonts and remote Unsplash images, so internet access is needed for those assets.

This is an original multi-page layout inspired by the clean industrial/scientific supplier style of the reference website. It is not an exact copy and is not affiliated with Ocean Instruments.
